# SafraX

Projeto educativo sobre expansão urbana, preservação das florestas e caminhos para cidades em equilíbrio com a natureza.

## Acesse o site

[Visitar o SafraX no GitHub Pages](https://alencar-arrow.github.io/Safra-x-plus/)

## Sobre o projeto

O SafraX reúne conteúdos sobre os efeitos da expansão urbana nos ecossistemas e apresenta alternativas de planejamento que consideram o território e as comunidades.

## Publicação

O site é publicado automaticamente no GitHub Pages a cada atualização na branch `main`.
