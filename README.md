### 🌿 Sobre o Projeto
Projeto educativo sobre expansão urbana, preservação das florestas e caminhos para cidades em equilíbrio com a natureza. O SafraX reúne conteúdos sobre os efeitos da expansão urbana nos ecossistemas e apresenta alternativas de planejamento que consideram o território e as comunidades.

### 💻 Tecnologias Utilizadas
- **HTML5** — Estruturação semântica do conteúdo
- **CSS3** — Estilização moderna e layout responsivo
- **JavaScript** — Interatividade e funcionalidades do site

### 🚀 Publicação
O site é publicado automaticamente via **GitHub Pages** a partir da branch `main` deste repositório.
